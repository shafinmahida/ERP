## 1. System Prompt for AI Assistants

When working in this repository:
1. **You are working on Dayar-E-Habib ERP**: A 100% offline desktop application for Hajj & Umrah travel operators.
2. **Never propose online API calls, cloud sync, or external dependencies**.
3. **Respect The Non-Negotiable Modeling Law**: `Customer`, `Booking`, `Registration`, `Room`, and `Flight` are decoupled entities.
4. **Follow The Calm ERP Design Bible**: Use global design tokens from `src/theme/tokens.ts` (Gold `#856936`, Cream `#FBF9F5`, Charcoal `#1E1A16`, `p-8` outer padding).
5. **Always verify code with `npx tsc --noEmit` and `npx tsx scratch/test_20_enterprise_scenarios.ts`**.
