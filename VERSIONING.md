# SEMANTIC VERSIONING POLICY

Dayar-E-Habib ERP follows **Semantic Versioning 2.0.0 (SemVer)**: `MAJOR.MINOR.PATCH`

- **MAJOR** (`1.x.x`): Major architectural updates or database schema restructures.
- **MINOR** (`x.2.x`): New operational modules (e.g. Travel Operations Module, Visa Engine).
- **PATCH** (`x.x.0`): Bug fixes, date parsing fixes, UI refinements, or performance patches.
